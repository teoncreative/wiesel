Wiesel Engine Documentation

Overview

Wiesel is a cross-platform game engine built with C++ and Vulkan, featuring a deferred PBR rendering pipeline, C# scripting via Mono, and a full-featured editor.

API Reference

The API is split into two main sections:

C++ Engine API

Core engine systems written in C++. Use these when building native plugins, editor extensions, or working on the engine itself.

  • Rendering - Renderer, pipelines, textures, materials, shaders, render features
  • Scene - Entities, components, scene management, serialization
  • Physics - Rigid bodies, colliders, mesh collider assets, raycasting
  • Audio - Audio manager, spatial sound, reverb zones
  • Asset System - Asset manager, loaders, serializers, VFS, handles
  • Animation - Skeletal animation, state machines, sprite animation
  • UI System - Canvas, RmlUi integration, text rendering, input routing
  • Input - Keyboard, mouse, gamepad, input contexts, multi-player
  • Editor - Editor layers, component inspectors, asset browser

C# Scripting API

Game-facing API for C# scripts. Attach scripts to entities by inheriting from WieselEngine.MonoBehavior.

  • MonoBehavior - Script lifecycle (OnStart, OnUpdate, OnDestroy, etc.)
  • Entity - Find, create, destroy entities, get components
  • Input - Keyboard, mouse, gamepad queries
  • Physics - Raycasting and overlap queries
  • Audio - Play sounds, music, spatial audio
  • Settings - Runtime graphics/audio settings
  • SceneManager - Scene loading and transitions
  • Console - Developer console commands
  • Time - Delta time, total time, frame count
