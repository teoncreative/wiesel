Detailed Description

template<typename Entity, typename Scene, typename... Components>
class Wiesel::TypedSystemFunction< Entity, Scene, Components >

Alternative system function wrapper using std::function.

This version uses type erasure to handle generic lambdas from WIESEL_BIND_FN. It's slightly less efficient but more flexible.
